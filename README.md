# Nexo · MVP Matemáticas 4.º Primaria

Primer MVP móvil del concepto **feed educativo finito**.

- Curso: 4.º de Primaria
- Comunidad: Cataluña
- Asignatura: Matemáticas
- Sesión: 10 actividades
- Adaptación básica por dominio
- Progreso guardado en localStorage
- Modo padres básico

El mapa curricular de `curriculum.json` está derivado de normativa y orientaciones oficiales, pero la granularización en microhabilidades es propia del producto y debe validarse pedagógicamente antes de producción.
